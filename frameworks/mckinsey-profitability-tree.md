# 麦肯锡盈利树

> 把企业的 ROE / 利润率拆解为收入 × 价格 × 量 × 成本 × 资本效率的"盈利树"诊断工具，用于识别边际改善的具体抓手。

## 起源与定位

"Profitability Tree" / "Margin Tree" / "Cost Tree" 是麦肯锡 1990s 后期至 2000s 在运营咨询与 corporate finance practice 中广泛使用的诊断框架 [需核实]。该工具与 BCG 经验曲线同属"成本与利润结构"分析家族，但其侧重不同——经验曲线关心"长期成本随累计产量的下降"，盈利树关心"当下利润率的拆解定位"。盈利树并非麦肯锡独占，多家咨询公司（BCG、Bain、Deloitte）都有类似工具 [需核实]。

## 核心内容

典型分解（以营业利润率为例）：

- **营业利润率 = (价格 − 单位成本) / 价格**
- 价格 = 产品组合加权价、客户分级价、渠道折扣后净价
- 单位成本 = 原材料 + 直接人工 + 制造费用 + 物流仓储 + 售后
- 进一步下钻：原材料 = BOM 单耗 × 采购单价

典型分解（以 ROIC 为例）：

- **ROIC = 营业利润率 × 资本周转率**
- 资本周转率 = 收入 / 投入资本
- 投入资本可再拆为：应收账款 + 存货 + 固定资产

使用流程：

- 选定根指标（ROIC / Operating Margin / EBIT）
- 对每个叶节点找出"我方 vs. 行业标杆"的差距
- 锁定差距最大的 2-3 个抓手，定改善目标

## 适用与不适用

**适用**：

- 成熟业务的利润诊断——找到利润率改善的具体抓手
- CEO 上任 90 天复核——把公司财务表现"翻译"为运营语言
- 并购整合后的成本协同识别——分项寻找"哪里能省"
- 行业下行期——快速识别"砍哪一块对利润冲击最小、影响最大"

**不适用**：

- 高速变化的初创公司——驱动力未稳定，强行拆解会得到误导性结论
- 纯财务重组（用 DuPont / 财务工程 / debt restructuring 更合适）
- 已陷入财务危机的企业（需要紧急止血，不是有条不紊的诊断）

## 局限与争议

- 盈利树概念在多家咨询公司通用——麦肯锡特定版本的细节不易独立验证 [需核实]
- 乘法分解掩盖了变量间的相关性——现实中价格、量、成本常常相互制约（提价会损量、压量会损毛利）
- 作为"诊断"工具有效，"改善建议"仍需深入行业与运营判断——避免"找出差距就开药方"
- [争议] 是否过度聚焦"分子分母"——忽视了组织能力、人心士气等软性驱动

## 与其他方法论的关系

- **同源工具**：BCG 经验曲线——盈利树关心"当下拆解"，经验曲线关心"长期走势"
- **配套**：价值链分析——可作为"成本侧"叶节点的进一步拆解工具
- **应用场景**：麦肯锡 7S 框架在组织诊断时，常以盈利树的差距作为切入点
- **批评后续**：活动基础成本法（Activity-Based Costing）、精益生产（Lean）等提供更细颗粒度的成本分析

# BCG 经验曲线

> 累计产量每翻一番，单位成本下降一个固定比例（典型 20-30%）的成本预测经验法则。

## 起源与定位

1960s 后期 [需核实]（多源指向 1966 或 1968）由 BCG 创始人 Bruce Henderson 安排 John Clarkeson 在 BCG 内部开发的成本预测工具，发表于 Henderson 的 "Perspective" 备忘录系列中（具体篇号 [需核实]）。该框架是 BCG 增长矩阵（1970）的成本逻辑基础，支撑了"追求市场份额 → 累计产量领先 → 单位成本领先"的论证。BCG 1972 年出版同名专著扩展此框架。

## 核心内容

核心命题：**累计生产经验每翻一番，单位成本下降一个固定比例**（典型斜率 70-80%，即 20-30% 成本下降）。

运作机制：

- 双对数坐标下，累计产量（X）与单位成本（Y）呈近似线性下降关系
- 斜率反映"经验效益"强度：70% 斜率（成本降到 70%）效应强于 90% 斜率
- 行业斜率差异大：半导体约 70%、装配制造 80-85% [需核实]

战略含义："市场份额领先 → 累计产量领先 → 单位成本领先 → 利润空间领先"。这是 BCG 增长矩阵"市场份额"轴的底层成本论证。

## 适用与不适用

**适用**：

- 制造业长期成本预测（汽车、半导体、消费电子）
- 并购整合中评估规模效应
- 解释份额领先者为何能持续盈利

**不适用**：

- 服务业、咨询、金融（学习效应微弱）
- 平台经济、网络效应业务
- 知识工作（创新成本与累计产量无直接关系）

## 局限与争议

- 斜率跨行业差异大，不能套用粗略经验值
- 假设过简：技术跳跃、规模经济被简化为"经验"
- 与学习曲线（learning curve）概念常被混用：学习曲线源自 Wright 1936 飞机制造业 [需核实]，关注工人个体学习速度；经验曲线把成本下降归因于整个组织与产业累积
- [争议] 服务业和平台经济中效应普遍不明显
- [争议] "份额优势自动转化为成本优势"——管理执行决定能否兑现

## 与其他方法论的关系

- **理论同源**：BCG 增长矩阵（1970）的成本逻辑基础，经验曲线是其背后的成本假设
- **概念对照**：学习曲线（learning curve）关注工人个体学习速度；经验曲线关注整个组织/产业累积
- **后续批评**：1980s 实证研究质疑斜率稳定性，强调技术跳跃的颠覆性

经验曲线是 BCG 的"看家工具"之一——也是 2020s 后被边缘化最严重的工具。

**经验层**：我用经验曲线做过几次成本预测项目。最有效的是给一家消费电子客户做"是否要扩产"决策——曲线显示该公司累计产量达到阈值后单位成本会显著下降，进而支撑"扩产"判断。客户用此说服了董事会。但经验曲线近 10 年越来越难用——我见过最关键的几次"失效"是技术跳跃造成的曲线断裂（如 LED 照明对传统灯泡、半导体新工艺对旧工艺）——经验曲线假设的"学习效率稳定"被新工艺彻底打破。

**判断层**：我用经验曲线做"长期成本预测的参照"多过"决策依据"。理由：经验曲线给出的是"行业平均的累计产量-成本关系"，但每个公司的实际曲线会有偏差（工艺路径、管理水平、规模经济）。我倾向把经验曲线当作"行业参照线"，再叠加客户实际历史数据评估"客户比行业好还是差"。这种"双源对比"比单看经验曲线可靠。

**反思层**：我对经验曲线最大的反思是"累计产量"这一变量本身。1960s 推出时这是清晰变量——实体工厂的累计产出。2020s 后累计产量的意义变了——SaaS 服务的"累计部署"是用户数，不是物理产出；汽车 OEM 的"累计产出"包括电动化转型后的新车型。曲线假设的"相同产品在累计产量下"前提被打破。我见过最严重的案例：一家消费电子公司用传统曲线预测新一代产品，结果新一代产品的累计产量定义与传统产品不直接可比——曲线失效。

**关联层**：经验曲线与其他工具的搭配——
- 与 `bcg-growth-share-matrix` 是同公司配套（曲线提供成本逻辑，矩阵提供分类）
- 与 `accenture-industry-x` 形成对比（曲线是 1960s 制造业思维，Industry X 是 2020s 数字化思维）
- 与 `mckinsey-profitability-tree` 是"成本 → 价值"链路（曲线给单位成本，价值树给价值构成）
- 与 Wright 1936 学习曲线直接连接（BCG 把"个体学习"扩展为"产业累积"）

**应用偏好**：我用经验曲线的场景：
- 长期成本预测（5 年以上单位成本走势）
- 制造业并购规模效应评估
- 解释行业份额领先者的成本优势

我不用经验曲线的场景：
- 平台 / 数字业务（累计产量定义变化）
- 技术跳跃期（曲线断裂）
- 服务业 / 知识工作（学习效应弱）

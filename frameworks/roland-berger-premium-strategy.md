# 罗兰贝格高端战略

> 罗兰贝格在高端品牌、汽车与工业领域积累的高端定位战略方法集合。

## 起源与定位

罗兰贝格（Roland Berger）1967 年成立于慕尼黑，是欧洲老牌战略咨询公司之一 [需核实]。其"高端战略"（Premium Strategy）相关工作长期聚焦于德国汽车 OEM（OEM, Original Equipment Manufacturer / 原始设备制造商）、欧洲奢侈品与高端工业品客户 [需核实]。与 MBB 相比，罗兰贝格的方法 IP 较不形式化——"高端战略"更接近在公司多个客户项目与行业报告中反复使用的工作语言集合，而非单一署名出版物；具体命名者、首发年份与正式出版物 [需核实]。

## 核心内容

工作语言层面包含若干反复出现的元素 [需核实]：

- **高端动因诊断**：识别客户愿意支付溢价的真实维度——品牌、性能、服务、稀缺性、设计、传承等
- **价值链高端化**：识别并强化那些能"撑起溢价"的关键活动（专属渠道、售后服务、品牌叙事、关键部件自研等）
- **客户分层与差异化定价**：把客户按愿付价格分层，配置与之匹配的产品 / 服务组合，避免对价格敏感客户进行无差别让利
- **品牌资产梳理**：把品牌资产从感性口号变为可量化、可视化的内部诊断工具
- **定价治理**：建立能维持溢价的内部机制（控制促销频次、限制折扣幅度、严守价格纪律）

核心假设是：高端溢价不是单一动作，而是一套必须配套的体系——任何单一环节（仅提价、仅换 LOGO）都会失败。

## 适用与不适用

**适用**：

- 欧洲豪华汽车 OEM 的品牌向上 / 平行品牌策略
- 高端奢侈品集团（皮具、腕表、烈酒等）的全球区域扩张
- 高端工业品（机床、特种设备、专业仪器）的差异化定价
- 已有品牌资产、寻求溢价化的成熟消费品企业

**不适用**：

- 纯成本竞争的快消 / 大众商品（市场逻辑不同）
- 品牌资产尚未积累的早期创业公司
- 监管严格定价的公用事业 / 医药（无法自由溢价）
- 商业模式以"低价获客 + 规模"为核心的互联网平台

## 局限与争议

- 罗兰贝格公开 IP 较 MBB 不够形式化——"高端战略"是方法集合而非单一署名框架，具体边界在不同项目中存在差异 [需核实]
- 该方法在汽车 OEM 与奢侈品行业的成功，是否能直接迁移到其他高端工业品仍需个案检验
- 强调"品牌资产"，对以成本 / 规模竞争的成熟行业不直接适用
- [争议] "高端定位"与波特"差异化战略"在概念边界上不清晰——前者是后者的细分应用还是独立方法 [争议]
- [争议] 高端溢价是否真正可持续：数字化让"奢侈符号"快速被复制（如奢侈品平价化产品线），传统高端边界正受挑战 [争议]

## 与其他方法论的关系

- **与波特三战略**：高端定位本质上是波特"差异化战略"在高端细分市场的具体应用——三战略给出"取什么方向"，罗兰贝格高端战略给出"如何在高端方向落地"
- **与 BCG 增长矩阵**：高端品牌通常占据"明星象限"（高增长 + 高份额），BCG 矩阵可以作为罗兰贝格高端战略组合决策时的参考坐标
- **与 ADL 价值迁移**：价值迁移理论关注"价值在产业链中的位移"，与高端战略中"识别价值真正来源"的思路互补
- **互补**：高端战略的客户分层思想与定价治理逻辑可与 Bain NPS（净推荐值）结合——NPS 高的高端客户是溢价真正可维持的群体

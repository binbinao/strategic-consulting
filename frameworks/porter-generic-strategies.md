# 波特三战略

> 把企业竞争战略归纳为三种"通用战略"——成本领先（cost leadership）/ 差异化（differentiation）/ 聚焦（focus，成本或差异化），主张企业必选其一。

## 起源与定位

1980 年由哈佛商学院教授 Michael Porter 在其著作《Competitive Strategy: Techniques for Analyzing Industries and Competitors》（Free Press, 1980）中系统提出。该框架与同期"五力"模型（Porter 1979 HBR 论文）共同构成 Porter 竞争战略体系；价值链分析（1985 *Competitive Advantage*）则是这套体系在公司层面的延伸。

## 核心内容

三种通用战略：

1. **成本领先（Cost Leadership）**：在行业内做最低成本生产者，靠规模、效率、议价压低成本。适用于价格敏感、标准化产品行业
2. **差异化（Differentiation）**：在客户重视的维度（品牌、技术、体验、服务）上做到独特，能收取溢价
3. **聚焦（Focus）**：在窄细分市场做成本领先或差异化。聚焦本身不是独立优势，而是把前两者收窄到细分市场

核心命题：企业必须**明确选择**一种三战略之一。"夹在中间"（stuck in the middle）的企业没有清晰定位，利润率最低。

战略落地逻辑：选择决定资源配置，活动系统（活动适配性）必须与战略一致。

## 适用与不适用

**适用**：

- 竞争战略起点（与五力分析配套）
- 现有业务定位诊断
- M&A 中评估目标公司的战略清晰度

**不适用**：

- 早期创业（行业 / 客户未定型）
- 纯运营改进（无战略选择必要）
- 监管保护行业（竞争不充分）

## 局限与争议

- 战略互斥假设过强：现实中"高端低成本"（如苹果）、多细分聚焦（多品牌组合）也能成功
- 聚焦战略的独立性争议：多数"聚焦"公司实质上是某细分里的差异化者
- 平台经济、网络效应下"低成本"概念被重新定义
- [争议] 平台模式下"赢家通吃"——三战略中"聚焦细分"逻辑失效
- [争议] 蓝海战略（W. Chan Kim）主张打破成本 vs 差异化的取舍，挑战该框架的根基
- 与五力分析配合使用：五力看行业吸引力，三战略看公司定位

## 与其他方法论的关系

- **理论同源**：Porter 五力模型（1979）看行业结构，三战略看公司定位，两者配套
- **理论同源**：Porter 价值链（1985）分析企业内部活动，活动适配性是三战略落地的工具
- **批评后续**：蓝海战略（W. Chan Kim）、Best Cost Provider 战略挑战"成本 vs 差异化"的二元对立
- **延伸**：聚焦战略衍生出利基市场策略（niche strategy）

三战略是我教新人时最常翻出来的工具——也是我最常与客户争论的工具。

**经验层**：我做过十几次三战略应用。最有用的一次是给一家消费品客户的董事会做战略评估——他们声称走"差异化"，但产品同质化严重、研发投入低、品牌溢价弱。我的三战略分析直接点出："你们的差异化不成立——你们实际上是'夹在中间'。"这个结论让董事会开始讨论产品组合重塑，不是空洞的"做差异化"。最糟的几次是把三战略当作 PPT 工具——客户的高管在会议室里"贴标签"但转身回到办公室仍按原来动作。框架没用，是因为"贴标签"和"按之行动"之间还隔着组织重塑。

**判断层**：我用三战略做"反共识诊断"，不做"标签工具"。理由：三战略最有价值的不是"你的战略是什么"——多数成熟公司已经心里有数，贴标签反而浪费。三战略的价值是"你的战略不成立"——揭示客户自我认知与现实的差距。我把三战略当作"反共识工具"用——找出客户"以为的差异化"中哪些是真实可维持的、哪些只是口号。这种诊断价值远高于"贴标签"。

**反思层**：我对三战略最大的反思是"互斥假设"过于刚性。现实中多数成功公司是"差异化 + 选择性低成本"——苹果是高端品牌 + 供应链大规模制造；Costco 是低毛利 + 高度精选。Porter 自己 1985 在 *Competitive Advantage* 中修订了部分观点——"整合 cost leadership"（即 Best Cost Provider）实际上能成功。框架的"互斥"假设是教学便利，真实市场更接近"以一为主、另一为辅"。我在做三战略评估时会主动问客户："你的'主'战略是什么，'辅'差异是什么？"——这比硬贴 3 个标签更贴近现实。

**关联层**：三战略与其他工具的搭配——
- 与 `porters-five-forces` 是 Porter 自洽组合（五力看行业，三战略看公司）
- 与 `value-chain` 形成"选择 + 落地"——三战略定方向，价值链配活动
- 与 `where-to-play-how-to-win` 是 OC&C 同一思想族（"定位 + 取舍"）
- 与"最佳成本提供者"（Best Cost Provider）概念是同源补充

**应用偏好**：我用三战略的场景：
- 客户战略自评与实际差距的诊断（"反共识工具"用法）
- 高层董事会的战略评议（逼表态场合）
- M&A 评估（看目标公司战略是否清晰与持续）

我不用三战略的场景：
- 单一业务 / 单一产品的早期公司（框架不适用）
- 平台经济 / 网络效应业务（成本/差异化逻辑失效）
- 监管保护行业（竞争不充分，三战略假设不成立）
- 已经清晰战略的公司（不需要框架，浪费）

# 阿什里奇组合展示

> 用"行业关键成功因素"代替单一市场份额的 2×2 portfolio 框架，把每个业务沿 CSF 表现评分后定位。

## 起源与定位

1990s 前期 [需核实] 由英国 Ashridge 商学院（前 Cranfield School of Management）的 Ashridge Strategic Management Centre 提出，主要开发者是 Michael Goold、Andrew Campbell 与 Marcus Alexander。该框架针对 BCG 矩阵"市场份额即一切"的批评，用"行业关键成功因素（CSF）"替代单一市场份额维度。Ashridge 不在 spec 定义的 14 家公司范围内，作为商学院独立方法被纳入。

## 核心内容

关键概念：**关键成功因素（Critical Success Factors / CSF）**——每个行业赢利的差异化要素。

工作流：

1. 对每个行业识别 2-5 项 CSF（如：技术领先、品牌、分销、低成本制造）
2. 把每个业务沿 CSF 评估表现（强 / 中 / 弱）
3. 计算加权"竞争优势得分"
4. 用 2×2 矩阵画出"行业吸引力 × CSF 表现"
5. 对每个落点差异化建议（投入 / 维持 / 收割）

## 适用与不适用

**适用**：

- 业务多元化且行业差异化显著的组合公司（典型如 GE、Siemens）
- 高科技、服务业等行业 CSF 明确的领域

**不适用**：

- 大宗商品等高度同质化行业（CSF 单一即"成本"）
- 单一业务公司

## 局限与争议

- CSF 主观性强，不同分析师可能给完全不同的因子集
- 行业 CSF 列表缺乏权威版本，需要团队共识建立
- 学派自身后续改进，如 "ladder of competitive advantage"
- [争议] Ashridge 的影响力较 MBB 弱，实务中常被 BCG / GE 矩阵替代

## 与其他方法论的关系

- **方法演变**：BCG 增长矩阵 → GE/McKinsey 矩阵 → Ashridge（去市场份额化）
- **同期方法**：Arthur D. Little 的 5 阶段生命周期 portfolio
- **应用层**：常作为 BCG / GE 矩阵的"补充视角"出现

Ashridge Portfolio Display 是 MBB 之外最被低估的 portfolio 框架——它对"市场份额即一切"的批评是 MBB 自己也承认的。

**经验层**：我用 Ashridge 做 CSF 分析的次数不多——主要在两类场景：(1) 客户业务横跨多个差异极大的行业（CSF 完全不同）；(2) 客户业务组合里有"看似市占率不高但实际竞争优势强"的隐藏冠军。这两类场景下 BCG 矩阵会误判（市场份额指标失真），Ashridge 的 CSF 视角反而更准确。最糟的一次是给一家业务高度同质化的化工客户做 CSF 分析——所有业务的 CSF 都是"成本"，最后评分变成"成本管理"PK，CSF 视角的优势完全消失。

**判断层**：我用 Ashridge 做"BCG 矩阵的修正视角"，不"替代 BCG"。理由：BCG 的市场份额维度是速查、Ashridge 的 CSF 维度是深入——两者不在同一层。如果客户用 BCG 矩阵给了一个业务"瘦狗"标签，我倾向用 Ashridge CSF 复检——"市场份额低但 CSF 表现强的话，重新分类"。这个"复检"流程比让客户二选一更现实，因为客户已经熟悉 BCG 框架。

**反思层**：我对 Ashridge 最大的反思是"CSF 共识问题"。CSF 列表本质上是"对行业成功的隐含假设"——这需要团队共识。但现实里团队共识很难达成——同一行业内不同分析师给的 CSF 列表可能差异 30% 以上。我见过最糟的案例：3 个分析师花了一周给出 3 个不同的 CSF 列表，最后只能 senior 拍板用"标准版"。这违背了 CSF 框架"对每个业务行业具体分析"的精神。我的偏好是先用 CSF 框架的"常见 5 因子"版本（规模/技术/品牌/成本/分销）做基线，再按客户行业做 2-3 项定制调整——而非完全从零开始。

**关联层**：Ashridge 与其他工具的搭配——
- 与 `bcg-growth-share-matrix` 是"市场份额 vs CSF"视角互补
- 与 `ge-mckinsey-matrix` 是"CSF 替代单一变量"的方向
- 与 `monitor-three-tests` 是同作者（Goold、Campbell）的不同框架（Monitor 看战略本身，Ashridge 看 CSF）
- 与 `oc-c-where-to-play-how-to-win` 是"位置 vs 表现"的搭配

**应用偏好**：我用 Ashridge 的场景：
- 客户业务跨多个差异极大行业
- 客户组合里有"看似市占率低但 CSF 强"的隐藏冠军
- BCG 矩阵评分有歧义时作为复检工具

我不用 Ashridge 的场景：
- 同质化行业（CSF 优势消失）
- 时间紧迫项目（CSF 共识成本高）
- 客户已经熟练 BCG 矩阵且无升级需求

- **应用角度**：CSF 思路其实比 BCG/GE 更贴你的行业吗？如果你在某个特定行业（如 SaaS、医疗、消费）做 portfolio，CSF 是先于市场份额的诊断维度——你能在不依赖市占率的前提下判断业务是否有竞争优势吗？
- **争议延伸**：本卡片提到 Andrew Campbell 是 Ashridge Portfolio Display 的共同开发者——他同时也是 Monitor Three Tests 的共同作者（Goold 是同一作者）。这两人从 Monitor 跳到 Ashridge 的一段历程本身是研究价值——可以读 *The Lords of Strategy* 看这段 1990s 西方战略咨询界的交叉流动。
- **CSF 主观性问题**：本卡片 `limitations` 提到 "CSF 主观性高，不同分析师可能给完全不同因子集"。这是 Ashridge 最知名的短板。你在做 CSF 分析时，团队如何达成共识？是采用 senior 拍板、还是多分析师 blind ranking 然后聚合？
- **与 BCG/GE 的精确对比**：Ashridge 在 MBB 之外。你见过的客户里，谁会用 Ashridge 替代 BCG/GE？谁会把它当补充？通常的边界是什么（行业差异化足够大）？
- **个人使用史**：你有过"明明市占率不高，但 CSF 表现很强"的业务吗？Ashridge 框架下应该会得到"投入"，而 BCG 框架下会被打入"问题"。这种情景你怎么处理？

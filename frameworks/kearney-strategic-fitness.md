# 凯纳战略适配度

> 用"竞争位置"与"运营效率"两个维度同时评估一家公司战略与执行整体适配度的诊断框架。

## 起源与定位

A.T. Kearney（2020 年品牌重塑后简称 Kearney）多年来作为公司内部使用的"战略体检"工具 [需核实]。"Strategic Fitness" 不是一个被单一文献系统化的"署名框架"，而是 A.T. Kearney 在多份客户报告与行业文章中反复使用的工作语言 [需核实]。该框架在 A.T. Kearney 2000s 之后的运营转型（Operational Transformation）与组合管理（Portfolio Management）业务中作为切入工具。具体命名者与首发年份 [需核实]。

## 核心内容

两轴构成 2×2 矩阵：

- **纵轴 - 竞争位置（Competitive Position）**：行业吸引力（市场规模、增长率、利润率、监管环境） + 公司相对竞争强度（份额、品牌力、研发能力）
- **横轴 - 运营效率（Operational Efficiency）**：成本位置（Cost Position，相对竞争对手的单位成本） + 资产效率（Asset Efficiency，固定资产 / 营运资本 / 库存周转）

四个象限的策略含义：

- **高竞争位置 + 高运营效率**：进攻 / 加大投入
- **高竞争位置 + 低运营效率**：先做运营改进再扩张——警惕"位置好但执行撑不住"
- **低竞争位置 + 高运营效率**：收割 / 短期现金流 / 寻找可迁移战场
- **低竞争位置 + 低运营效率**：重组 / 退出

核心诊断逻辑：两轴**同时**评估，单独看任一轴都可能给出误导结论。

## 适用与不适用

**适用**：

- 多元化集团的组合复盘与"投资 / 持有 / 退出"决策
- 运营转型项目的起点诊断——哪些业务的"运营效率"短板在拖累战略
- CEO 层级的战略体检：一次高层会议铺开两轴打分

**不适用**：

- 单一业务的短期战术选择（颗粒度过细）
- 尚未明确主业的初创公司（两轴都无法稳定打分）
- 行业结构性剧变期——两轴坐标本身在快速漂移
- 强监管 / 公共事业类业务，"竞争位置"概念被显著扭曲

## 局限与争议

- 两轴评分的主观性较高，尤其"运营效率"在服务、平台、硬件等不同模式下难以直接对比
- 公开文献较少，方法细节在不同 A.T. Kearney 出版物与客户项目间存在差异 [需核实]
- 与 GE / McKinsey 9 格矩阵在"竞争位置"维度重叠，与价值链分析在"运营效率"维度重叠——是否构成独立方法学贡献 [争议]
- "Strategic Fitness" 一词在咨询业内有不同用法——A.T. Kearney 的具体版本与其他公司"fitness"类诊断是否同源 [争议]
- 框架更接近"打分诊断"而非"诊断 + 行动建议"——落到具体业务需要配套转型方法

## 与其他方法论的关系

- **竞争位置侧**：与波特五力同源——五力是行业吸引力的结构性分析，凯纳战略适配度把其简化为单轴打分
- **运营效率侧**：与波特价值链分析互补——价值链回答"活动层效率从哪里来"，本框架只看"总体效率水平"
- **组合视角**：与 BCG 增长矩阵、GE / McKinsey 矩阵同属"组合评估"家族，但本框架多一个"运营效率"轴，组合 + 执行同时看
- **同公司其他方法**：A.T. Kearney 的运营转型（Procurement / Operating Model）等项目常把本框架作为入口
- **应用层**：常被作为后续运营改进项目的"哪里要先动"决策依据

## 个人批注

Kearney Strategic Fitness 是 2000s 后期战略管理流派里"把 portfolio 与 operations 合并诊断"的一个尝试——它填补了 BCG/GE 的"组合分析"与价值链的"运营分析"之间的空白。

**经验层**：我用 Kearney Strategic Fitness 的次数不多——主要在给制造业客户做组合 + 运营转型双重诊断时。最有效的场景是：当客户的"组合问题"和"运营问题"其实是同一个——例如某业务的"运营效率低"是它在"竞争位置"中的真实短板，而不是孤立症状。Kearney 两轴同时打分的设计正好捕捉这种联动。我见过最糟的是几个服务类客户——"运营效率"在不同业务模式下（咨询 vs SaaS vs 制造业）无法直接对比，导致评分失去意义。

**判断层**：我用 Kearney 做"组合 + 运营联动诊断"，不做"纯 portfolio 评估"或"纯运营评估"。理由：单做 portfolio（BCG/GE）只看出"该不该投"，单做运营（价值链）只看出"哪里效率低"，两者不能联动。Kearney 的"竞争位置 × 运营效率"两轴组合天然适合联动诊断——但前提是客户能接受"两个轴都打分"的复杂度。如果客户是"我只要看 portfolio"的诉求，Kearney 太重。

**反思层**：我对 Kearney Strategic Fitness 最大的反思是"2 轴 vs 9 轴 vs 4 轴"的"复杂度 vs 实用性"权衡。Kearney 2 轴是"最简"——但简化的代价是打分模糊性高（5 档评分本身就难）；BCG 4 轴是"中间"——颗粒度更粗但每格更明确；GE/McKinsey 9 轴是"最细"——但打分复杂度极高。咨询实践中我没见过"对什么场景用哪个粒度"的一致标准——更多是看客户偏好与项目预算。我的偏好：Kearney 2 轴做"快速对话"，BCG 4 轴做"组合决策"，GE 9 轴做"深度 portfolio review"。

**关联层**：Kearney Strategic Fitness 与其他工具的搭配——
- 与 `porters-five-forces` 同源（"竞争位置"侧五力分析）
- 与 `value-chain` 同源（"运营效率"侧价值链）
- 与 `bcg-growth-share-matrix` / `ge-mckinsey-matrix` 是 portfolio + 运营的同族
- 与"运营转型"框架（Kearney 自家、Kotter 8-Step）是"诊断 + 行动"组合

**应用偏好**：我用 Kearney Strategic Fitness 的场景：
- 制造业集团组合 + 运营联动诊断
- 客户需要"两轴同时看"的快速高层会议
- 已决定要动组织 + 组合的客户（Kearney 提供组合 / 运营的同步视角）

我不用 Kearney Strategic Fitness 的场景：
- 服务 / 平台 / 数字业务（运营效率轴难比）
- 单一业务公司（颗粒度浪费）
- 客户只想要 portfolio 视角（用 BCG 更直接）

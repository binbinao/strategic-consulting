# 凯纳战略适配度

> 用"竞争位置"与"运营效率"两个维度同时评估一家公司战略与执行整体适配度的诊断框架。

## 起源与定位

A.T. Kearney（2020 年品牌重塑后简称 Kearney）多年来作为公司内部使用的"战略体检"工具 [需核实]。"Strategic Fitness" 不是一个被单一文献系统化的"署名框架"，而是 A.T. Kearney 在多份客户报告与行业文章中反复使用的工作语言 [需核实]。该框架在 A.T. Kearney 2000s 之后的运营转型（Operational Transformation）与组合管理（Portfolio Management）业务中作为切入工具。具体命名者与首发年份 [需核实]。

## 核心内容

两轴构成 2×2 矩阵：

- **纵轴 - 竞争位置（Competitive Position）**：行业吸引力（市场规模、增长率、利润率、监管环境） + 公司相对竞争强度（份额、品牌力、研发能力）
- **横轴 - 运营效率（Operational Efficiency）**：成本位置（Cost Position，相对竞争对手的单位成本） + 资产效率（Asset Efficiency，固定资产 / 营运资本 / 库存周转）

四个象限的策略含义：

- **高竞争位置 + 高运营效率**：进攻 / 加大投入
- **高竞争位置 + 低运营效率**：先做运营改进再扩张——警惕"位置好但执行撑不住"
- **低竞争位置 + 高运营效率**：收割 / 短期现金流 / 寻找可迁移战场
- **低竞争位置 + 低运营效率**：重组 / 退出

核心诊断逻辑：两轴**同时**评估，单独看任一轴都可能给出误导结论。

## 适用与不适用

**适用**：

- 多元化集团的组合复盘与"投资 / 持有 / 退出"决策
- 运营转型项目的起点诊断——哪些业务的"运营效率"短板在拖累战略
- CEO 层级的战略体检：一次高层会议铺开两轴打分

**不适用**：

- 单一业务的短期战术选择（颗粒度过细）
- 尚未明确主业的初创公司（两轴都无法稳定打分）
- 行业结构性剧变期——两轴坐标本身在快速漂移
- 强监管 / 公共事业类业务，"竞争位置"概念被显著扭曲

## 局限与争议

- 两轴评分的主观性较高，尤其"运营效率"在服务、平台、硬件等不同模式下难以直接对比
- 公开文献较少，方法细节在不同 A.T. Kearney 出版物与客户项目间存在差异 [需核实]
- 与 GE / McKinsey 9 格矩阵在"竞争位置"维度重叠，与价值链分析在"运营效率"维度重叠——是否构成独立方法学贡献 [争议]
- "Strategic Fitness" 一词在咨询业内有不同用法——A.T. Kearney 的具体版本与其他公司"fitness"类诊断是否同源 [争议]
- 框架更接近"打分诊断"而非"诊断 + 行动建议"——落到具体业务需要配套转型方法

## 与其他方法论的关系

- **竞争位置侧**：与波特五力同源——五力是行业吸引力的结构性分析，凯纳战略适配度把其简化为单轴打分
- **运营效率侧**：与波特价值链分析互补——价值链回答"活动层效率从哪里来"，本框架只看"总体效率水平"
- **组合视角**：与 BCG 增长矩阵、GE / McKinsey 矩阵同属"组合评估"家族，但本框架多一个"运营效率"轴，组合 + 执行同时看
- **同公司其他方法**：A.T. Kearney 的运营转型（Procurement / Operating Model）等项目常把本框架作为入口
- **应用层**：常被作为后续运营改进项目的"哪里要先动"决策依据

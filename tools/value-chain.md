# 价值链分析

> 把企业拆解为 5 项主要活动 + 4 项支持活动的诊断工具，用于识别竞争优势的具体来源。

## 起源与定位

1985 年由哈佛商学院教授 Michael Porter 在《Competitive Advantage: Creating and Sustaining Superior Performance》一书中首次提出。Porter 价值链与同期的 Porter 五力共同构成其"竞争战略"理论体系：五力看行业层面的吸引力，价值链看公司层面的竞争优势来源。

## 核心内容

主要活动（Primary，5 项）：进向物流 / 运营 / 出向物流 / 市场与销售 / 服务——依次为原料输入、生产转化、成品输出、营销与售后。

支持活动（Support，4 项）：公司基础设施、人力资源管理、技术开发、采购——支撑主要活动运转。

价值（Margin）= 客户愿付价格 − 各活动成本。战略选择基于"哪一项活动的差异化或成本优势最强"。

## 适用与不适用

**适用**：

- 制造型企业的竞争战略制定
- 成本结构的逐项拆解
- 差异化路径的具体落地

**不适用**：

- 纯平台/数字业务（活动边界模糊，价值主要在网络效应）
- 单一财务表现诊断（应用 4C / DuPont 更合适）
- 非营利组织（驱动力是使命而非利润）

## 局限与争议

- 以制造业思维为原型，对纯服务/数字产品适配性较弱
- 活动之间的相互依赖被低估——现实中活动是网状而非线性流水线
- "价值"概念依赖定价模型，对免费/补贴型业务难适用
- [争议] Porter 后续在《Competitive Advantage》(1998 更新版) 把框架扩展到"价值系统"——跨企业边界
- [争议] 数字化时代"主要活动 vs. 支持活动"区分是否仍清晰

## 与其他方法论的关系

- **互补**：Porter 五力分析行业层面的吸引力，价值链分析公司层面的优势来源
- **应用**：SWOT 中的"内部优势"部分常借由价值链拆解得到
- **替代/补充**：McKinsey 内部活动分解（Operations / Organization / 等）有类似思路但更简化
- **批评后续**：Hammer & Champy 的"业务流程再造 (BPR)"、活动基础成本法（Activity-Based Costing）对其有修正

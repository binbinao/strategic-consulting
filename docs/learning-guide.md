# 学习路线指南

> 本库 42 张方法卡的阅读地图。事实层由 AI 起草并交叉核对，个人批注层是 owner 视角的学习笔记（AI 代笔、owner 否决）——本指南把批注层沉淀出的阅读线整理成一条可执行的路径。

## 卡片分三类

- **Frameworks**（31 张）：咨询公司 / 学派的招牌方法论，讲大图景
- **Processes**（2 张）：咨询工作方式本身——MECE、假设驱动问题解决
- **Tools**（9 张）：单项分析工具，上手最快

## 六条阅读线 + 一条支线

### 线 1 · 问题解决流程线（建议先学）

MECE / 议题树 → 明托金字塔原理 → 假设驱动问题解决

顺序理由：拆骨架 → 重组输出 → 定向验证。批注层钩子：建库过程本身就是一条活的假设驱动循环（Batch 4 杜撰人名被审查抓出、7S 年份被修正），学这条线时可以直接对照 git 历史。

### 线 2 · 宏观与行业线（作业主战场）

PESTEL → 情景规划（PESTEL 的动态升级）；五力 → 三种基本战略 → 价值链 → SWOT（汇总层）

作业：把新闻用 P/E/S/T/E/L 六个字母打标；"行业漫步"——选一个你熟悉的行业，把五力→三战略→价值链完整走一遍。

### 线 3 · 增长与组合线

安索夫矩阵 → BCG 增长矩阵 → 麦肯锡三 Horizons（增长三角）；组合深度：GE/McKinsey 矩阵 → Ashridge → ADL 矩阵；空间维度：蓝海战略

作业：同一条公司新闻用安索夫象限 + H1/H2/H3 双滤镜打标，体会"两个滤镜、一份材料"。

### 线 4 · 财务与绩效线

盈利树（分解症状）→ Monitor 价值管理（翻译成价值口径）→ 平衡计分卡（翻译成执行指标）；客户维度的具体 KPI：Bain NPS

作业：给一家你常用的上市公司手画两层盈利树，标出哪些叶子没有公开数据；给本库或自己的学习立一张四维迷你计分卡，每季复盘。

### 线 5 · 组织线

麦肯锡 7S → Galbraith 星模型 → BCG 组织优势 → Deloitte 商业化学反应

视角递进：从"要素对齐"到"设计参数"再到"具体的人"。批注层钩子：7S 卡的年份修正（1978→1980）是事实核查纪律的活案例。

### 线 6 · 客户体验线

NPS → 客户费力度 CES → 客户之声 VoC → 服务利润链

消费端视角最强的一条线——被调查者经验可以直接迁移。批注层钩子："我给了 9 分但从不推荐任何人"的言行不一自证。

### 支线 · 风险与不确定性

Oliver Wyman 企业风险管理 → OW 风险定价；上游：情景规划

作业（承诺在案）：写一份三行风险偏好陈述。

## 入门顺序建议（如果只学 8 张）

SWOT → 五力 → 安索夫 → MECE → 明托 → BCG 增长矩阵 → 三 Horizons → 盈利树

原则：先工具后框架、先眼熟后陌生——用"我认识这个词"的先手建立信心，再进入结构性内容。

## 作业清单（散落各卡批注的承诺汇总）

1. 新闻 P/E/S/T/E/L 打标（PESTEL）
2. 行业漫步：五力 → 三战略 → 价值链（波特三卡）
3. 安索夫象限 + H1/H2/H3 双滤镜打标新闻（安索夫 / 三 Horizons）
4. TOWS 配对：给熟悉的小店填四格再配四条策略（SWOT）
5. ERRC 四步动作格填奶茶店（蓝海战略）
6. 手画两层盈利树 + 标注无公开数据的叶子（盈利树）
7. 四维迷你计分卡，季度复盘（平衡计分卡）
8. 两个替补情景 + 预警指标，选一个真实长期决定（情景规划）
9. 三行风险偏好陈述（OW ERM）

## 分层协作机制

- **事实层**（AI 起草、交叉核对）：起源 / 核心 / 适用 / 局限 / 关系五节，每节 ≤300 字，不杜撰（查不到标 [需核实]）、争议标 [争议] 并给双方观点
- **个人批注层**（owner 否决）：经验 / 判断 / 反思 / 关联 / 应用偏好五层 + AI 建议；全部为 AI 代笔草稿，owner 保留改写否决权
- **status 生命周期**：draft → fact-checked → annotated → archived；当前 42/42 annotated
- **已知悬账**：OC&C 卡事实层未交叉核对（库内唯一一张）
- **维护命令**：`python3 tools/check-schema.py && python3 tools/check-links.py`

# 术语表

> 中英对照，按主题分组。术语在本库卡片内首次出现时均为中英并写，此表作汇总检索用。

## 通用工作语言

- **MECE / 相互独立、完全穷尽**：拆问题时不重不漏的黄金标准
- **Issue tree / 议题树**：把问题拆成可回答的子议题
- **Hypothesis-driven / 假设驱动**：先立答案再找证据的工作方式
- **Pyramid Principle / 金字塔原理**：结论先行的表达结构
- **KPI / 关键绩效指标**：可衡量的目标代理变量
- **Leading / lagging indicators / 领先 / 滞后指标**：报"因"与报"果"的两类指标

## 增长与组合

- **Market Penetration / 市场渗透**：现有产品 × 现有市场（安索夫四象限之一）
- **Market Development / 市场开发**：现有产品 × 新市场
- **Product Development / 产品开发**：新产品 × 现有市场
- **Diversification / 多元化**：新产品 × 新市场，风险最高
- **H1 / H2 / H3**：核心业务 / 新兴机会 / 未来选项（三 Horizons）
- **Cash cow / question mark / star / dog**：BCG 增长矩阵四格
- **Value innovation / 价值创新**：差异化与低成本同时追求（蓝海）
- **ERRC / 剔除-减少-增加-创造**：蓝海四步动作框架
- **Strategy canvas / 战略布局图**：可视化行业竞争要素的曲线图
- **Red / blue ocean / 红海 / 蓝海**：已知血拼市场 vs 无人争抢新空间
- **CSF / 关键成功因素**：Ashridge 用其替代单一组合指标

## 竞争与行业

- **Five Forces / 五力**：行业竞争结构的五股力量
- **Generic strategies / 三种基本战略**：成本领先、差异化、聚焦
- **Value chain / 价值链**：把企业拆成创造价值的基本活动与支持活动
- **Servitization / 服务化**：卖设备改为卖可用小时数等服务的转型

## 宏观与不确定性

- **PESTEL**：政治 / 经济 / 社会 / 技术 / 环境 / 法律六维扫描
- **Scenario / 情景**：合理且分歧的未来路径，非预测
- **Official future / 官方未来**：组织从不检查的默认剧本
- **Robust strategy / 稳健战略**：在多数情景下都站得住的战略
- **Early warning indicators / 预警指标**：提示"正在滑向哪个情景"的信号

## 组织

- **7S**：战略、结构、制度、风格、人员、技能、共同价值观
- **Star model / 星模型**：策略、结构、流程、回报、人五要素
- **Business Chemistry / 商业化学反应**：Pioneer / Guardian / Driver / Integrator 四种工作风格
- **OT / IT**：运营技术 / 信息技术（工业数字化的分界线）

## 绩效与财务

- **ROIC / 投入资本回报率**：盈利树与价值管理的共同母指标
- **Profit tree / 盈利树**：ROIC = 利润率 × 资本周转的因式分解
- **EVA / 经济增加值**：扣除资本成本后的利润口径
- **DCF / 现金流折现**：把未来现金流折成现值
- **Tobin's Q**：市值 / 重置成本的价值口径
- **Balanced Scorecard / 平衡计分卡**：财务 / 客户 / 流程 / 学习四维执行系统
- **Strategy map / 战略地图**：四维间 if-then 因果链的可视化

## 客户

- **NPS / 净推荐值**：推荐者 − 贬损者的单一客户指标
- **CES / 客户费力度**：办成一件事有多费劲
- **VoC / 客户之声**：客户原话的系统性采集
- **Service profit chain / 服务利润链**：员工满意 → 服务价值 → 客户满意 → 增长的链式因果

## 风险与交易

- **ERM / 企业风险管理**：风险偏好 — 识别 — 应对的全公司框架
- **Risk-based pricing / 风险定价**：按风险水平差异化报价
- **CDD / 商业尽职调查**：投资前的市场 / 竞争 / 客户 / 运营 / 管理五维核查
- **[争议] Buyer-funded independence / 买方出资的独立性**：尽调行业的结构性利益冲突
